 Portafolio de Samir Schenfeld

Portafolio personal de programación hecho con HTML, CSS y JavaScript, sin librerías externas.

## Qué contiene

- **Proyectos:** sistema de gestión de compras, ventas y stock; sistema de gestión de usuarios; e-commerce Sabores Express; e-commerce Kiosco Escolar.
- **Experiencia:** prácticas profesionales en el Municipio de Lomas de Zamora y atención al público en emprendimientos familiares.
- **Formación y conocimientos:** Escuela Técnica N.º 7 Manuel Sadosky e ingreso previsto a Ingeniería Informática.
- **Documentación:** bitácora de trabajo con fecha, proceso, título y actividad.
- **CV:** botón para descargar el CV en PDF e imprimirlo.

## Estructura del repositorio

```
index.html               Estructura y contenido de la página
style.css                Estilos (colores, tipografía y adaptación a celulares)
script.js                Año del pie de página y menú que marca la sección activa
foto.jpg                 Foto de perfil
sabores-gerente.jpg      Foto de trabajo de un proyecto
kiosco.jpg               Foto de trabajo de un proyecto
CV_Samir_Schenfeld.pdf   CV para descargar
```

## Cómo verlo

1. Descargá o cloná el repositorio.
2. Abrí `index.html` en el navegador.

También se puede publicar gratis con GitHub Pages (Settings, Pages, rama `main`).

## Tecnologías

HTML5, CSS3 (variables, grid y flexbox) y JavaScript.
